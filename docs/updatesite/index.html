EclipseLlama Update Site

This is the p2 update site for the EclipseLlama plugin.

Installation Instructions

  1. Open Eclipse IDE
  2. Go to Help → Install New Software...
  3. Click Add...
  4. Enter Name: EclipseLlama
  5. Enter Location: https://vijaytank.github.io/eclipsellama/updatesite/
  6. Select EclipseLlama and follow the installation wizard.
